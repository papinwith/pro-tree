# สำรองและกู้คืนข้อมูลทั้งเว็บ

แอดมิน → **สำรองข้อมูล** (`admin/backup.php`, ต้องมีสิทธิ์ settings.manage)

## สำรอง
- **ดาวน์โหลดสำรองทั้งเว็บ (.zip)** — ฐานข้อมูลทั้งหมด (`database/backup.sql`, รวมภาพหมุน 360° และข้อมูลฝึกโมเดล) + รูปที่อัปโหลด (`uploads/`) + `README.txt` + `manifest.json`
  - QR code ไม่รวม (สร้างใหม่จากรหัสต้นไม้ได้)
  - ไฟล์ถูกส่งต่อเนื่องทีละชิ้น ไม่กินหน่วยความจำ แม้รูปเยอะ
- **เฉพาะฐานข้อมูล (.sql)** — ไม่มีรูป

เก็บไฟล์ไว้นอกเซิร์ฟเวอร์ (Google Drive / external drive) ตามรอบ เช่นสัปดาห์ละครั้ง

## กู้คืน
1. ฐานข้อมูล: สร้างตารางด้วย `docs/install.postgres.sql` แล้วรัน `psql "$DATABASE_URL" -f database/backup.sql` (ไฟล์จะล้างตารางที่จะเติมก่อน — ใช้กับระบบที่ต้องการกู้เท่านั้น)
2. รูป: หน้าสำรองข้อมูล → "กู้คืนรูปจากไฟล์สำรอง" เลือกไฟล์ ZIP (ไฟล์ที่มีอยู่แล้วไม่ถูกทับ รับเฉพาะรูปจริงใน tree/species/maps/logo) — ถ้า ZIP ใหญ่กว่า `upload_max_filesize` ของเซิร์ฟเวอร์ ให้คัดลอกโฟลเดอร์ `uploads/` ไปที่ `public/assets/uploads/` โดยตรง

ข้อจำกัด: ZIP ไม่เกิน 4 GB / 65,535 ไฟล์
